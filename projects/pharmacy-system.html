Pharmacy Management System

A comprehensive pharmacy system featuring medicine inventory management, batch tracking, FEFO expiry alerts, POS transactions, audit logs, and sales reports.

Role

Full-Stack Developer

Core Features
  • FEFO Batch Logic
  • Barcode Checkout
  • Low Stock Notifications
  • Audit Trail Logging

Project Overview

Designed for pharmaceutical operations, this application enforces First-Expiring-First-Out (FEFO) dispensing rules, prevents accidental distribution of expired stock, speeds up checkout cashiering, and delivers clean daily financial reports.
