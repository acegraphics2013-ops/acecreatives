Project Overview

The Health Promotion Unit (HPU) receives numerous requests daily for graphic design, print artwork, IEC (Information, Education, and Communication) materials, video coverage, and media production. Managing these requests manually resulted in delayed approvals, untracked progress, and communication bottlenecks.

The Problem

Prior to system implementation, requests were submitted via paper forms or scattered messaging apps. Requesters had no visibility into job progress, and section leads struggled to assign tasks, evaluate operator performance, or monitor large-format printing queues.

Objectives

  • Centralize request submission through a unified web portal.
  • Implement role-based approval workflows for section leads and division heads.
  • Introduce QR code tracking for physical job tickets and print production.
  • Provide real-time Kanban status tracking and client evaluation feedback.

Solution & Architecture

Built with PHP and MySQL, the platform features a responsive web interface tailored for both desktop operators and mobile requesters. A custom Kanban workflow system updates task status seamlessly, while integrated QR code generation attaches unique tracking IDs to every approved job order.

Key Features

Role-Based Access (RBAC)

Tailored interfaces for Requesters, Designers, Print Operators, and Executive Approvers.

Approval Workflows

Multi-stage verification ensuring artwork quality and official divisional clearance.

QR Code Tracking

Instant mobile scanning to verify job ticket status on the production floor.

Interactive Kanban Board

Drag-and-drop job stages from Intake → Design → Proofing → Production → Completed.

Results & Impact

65% Faster Turnaround
100% Traceable Job Tickets
98% Client Satisfaction
