Project Overview

PHU KPI-DPMS (Data Performance Management System) is an enterprise reporting dashboard built for tracking Key Performance Indicators across multiple health units, monitoring quarterly accomplishments, and generating institutional performance reports.

The Problem

Reporting units previously submitted KPI figures via disconnected spreadsheet files. Aggregating data for quarterly management reviews required dozens of manual copy-paste hours, leaving data prone to mathematical inconsistencies and lacking secure revision histories.

Solution & Features

Developed using Node.js and MySQL, the system provides automated metric calculation, real-time variance analysis against set quarterly benchmarks, role-based access control (RBAC), and printable executive PDF summaries.
